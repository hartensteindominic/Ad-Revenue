# UI V2

The home experience is intentionally mobile-first and action-first.

Primary actions: Find objects, Scan a receipt.

Secondary surfaces: Room, AI, Marketplace, Passport.

The main screen keeps copy short and moves legal/detail content to dedicated pages. Object cards prioritize fast 3D previews, USD price, and physical/NFT/QR identity. The navigation uses Find, Scan, Room, and AI.
